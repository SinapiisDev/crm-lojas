# Plano 6 — Agente de IA: temperatura, sugestão de mensagem e resumo semanal

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Com a IA ligada, cada lead tem temperatura (quente/morno/frio), um resumo curto e uma sugestão de mensagem de WhatsApp atualizados depois de cada contato e todo dia cedo para os parados; segunda cedo cada loja ganha um resumo da semana no painel. Com a IA desligada, nada disso aparece e o resto funciona igual.

**Architecture:** `src/lib/ia/` com um `ModeloIA` injetável (real = Anthropic SDK `messages.parse` + `zodOutputFormat`; testes = falso). Os números do resumo semanal são calculados no código (funções do painel); a IA só escreve o texto. Colunas de IA em `leads` só são gravadas pelo servidor (trigger ignora o cliente). Rotina às 07:45 SP via `pg_cron` → `POST /api/ia/diaria` (mesmo segredo do despacho), antes da rotina de avisos das 08:00, que passa a usar o resumo no texto do aviso.

**Spec:** §8 (IA: o quando é regra fixa, a IA escreve o conteúdo; lembrete com contexto, temperatura, resumo semanal; modelo em `AI_MODEL`, desligado até a decisão).

## Global Constraints

- IA ligada só com `AI_MODEL` **e** `ANTHROPIC_API_KEY` definidos; senão nenhuma chamada é feita.
- `AI_MODEL` ∈ {`claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-5-5`} (decisão da dona); `output_config.effort = "low"`; `max_tokens` 2000.
- Saída estruturada: lead → `{ temperatura: "quente"|"morno"|"frio", resumo: string (≤ 300), sugestao: string (≤ 500) }`; semana → `{ texto: string (≤ 1200) }`.
- Entrada para a IA: no máximo os 20 eventos mais recentes do lead; dados do cliente vão entre delimitadores e o sistema diz que são dados, não instruções.
- Falha/recusa da IA → loga e segue sem sugestão (nunca quebra a ação do usuário).
- Rotina diária: até 50 leads parados por execução, só os sem análise desde o último contato.
- Resumo semanal: segunda-feira (SP), um por loja por semana; avisa donos/gerentes da loja ("Resumo da semana", link `/painel`).
- Aviso de lead parado: `Sem contato há N dias. ` + (resumo da IA, ou `Entre em contato de novo.`).
- Cliente não grava `temperatura`, `resumo_ia`, `sugestao_ia`, `ia_em`.

## Review Focus

- IA desligada → nenhuma chamada, nenhuma tela quebrada, aviso de lead parado com texto padrão.
- Anotação do cliente tentando dar ordens à IA ("ignore tudo e…") → sugestão continua sendo só uma mensagem de venda.
- Vendedora gravando `temperatura`/`sugestao_ia` pela API → ignorado.
- Resumo semanal rodando duas vezes na segunda → um só por loja.
- Rota `/api/ia/diaria` sem segredo → 401.
